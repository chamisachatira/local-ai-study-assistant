\# Local AI Study \& Teaching Assistant



A locally-hosted RAG (Retrieval-Augmented Generation) AI assistant built with Flask, Ollama (`llama3.2`), and web/document scraping capabilities. Designed to assist with study materials, lesson planning, and retrieving relevant institutional context.



\---



\## Features

\- \*\*Local Document RAG\*\*: Parses and searches local PDFs, DOCX, and text files.

\- \*\*Web Context Integration\*\*: Scrapes and incorporates context from external web pages.

\- \*\*Privacy-First LLM\*\*: Powered by Ollama running `llama3.2` completely offline.

\- \*\*Web Interface\*\*: Lightweight web GUI built with Flask.



\---



\## Prerequisites

Before running the application, make sure you have the following installed:

1\. \*\*Python 3.10+\*\*: Download and install from \[python.org](https://www.python.org/).

2\. \*\*Ollama\*\*: Download and install from \[ollama.com](https://ollama.com/).

3\. \*\*Git\*\*: Installed on your system.
